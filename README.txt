# UFV FORGE Pitch Website

## Open locally
1. Extract `UFV_FORGE_website.zip`.
2. Open `index.html` in a browser.

For best results, serve the folder through a local static server (for example, VS Code Live Server) so all assets and the PDF behave consistently.

## Website structure
- `index.html` — interactive pitch landing page
- `vision.html`, `hub.html`, `budget.html`, `timeline.html`, `delivery.html`, `impact.html`, `why.html` — supporting pages
- `assets/UFV-Forge-Full-Report.pdf` — full 18-page project charter and management pre-plan
- `assets/` — CSS, JavaScript, logo and images

All figures are presented as proposal targets, not approved commitments. The timeline uses the report's three formal kill points: June 2028, May 2030 and August 2030.
