UFV FORGE — Interactive project pitch website

HOW TO RUN
1. Extract the complete ZIP folder.
2. Open the folder in VS Code.
3. Run index.html with Live Server (recommended), or open index.html directly in a browser.
4. Use the top navigation to move between the dedicated pages. The logo returns to Home.

PAGES
- index.html: short pitch and overview
- vision.html: the core idea and opportunity
- hub.html: the labs, student sandbox and interactive student pathways
- budget.html: clickable investment allocations and operating model
- timeline.html: project sequence and milestones
- delivery.html: decision gates and project risks
- impact.html: interactive stakeholder perspectives and outcome targets
- why.html: decision conditions and key objections

INTERACTIONS
- Responsive mobile navigation
- Interactive tabs on The Hub and Impact pages
- Expandable budget allocations and FAQs
- Animated investment bars and reveal effects
- Press P for presenter mode; arrow keys move through sections; Esc exits

The full report is available separately from the site. The website is designed as a concise pitch, not a replacement for the report. All figures are proposed planning estimates and not approved commitments.
