Cyber range

A controlled environment for practising attack detection, investigation and defence without putting UFV’s everyday network at risk.

  • Logging and incident exercises
  • Hands-on security workflows

  • AI and data processing
  • Research experiments
  • Shared compute resources

  • Sensors and microcontrollers

  • Prototype and test cycles

What would you build here?

Pick a starting point to explore how a student might use the hub.

Cybersecurity

Investigate. Detect. Respond.

Work in an isolated cyber range, inspect logs, practise incident response and learn how to harden the services you operate.

Takeaway: experience with defensive workflows in a controlled environment.

AI & high-performance computing

Run work your laptop cannot.

Use shared compute resources for data processing, AI experiments and research workloads that need more processing power, memory or storage.

Takeaway: practical experience managing compute-heavy work.

IoT & embedded systems

Bring software into the physical world.

Connect sensors and microcontrollers, test device communications and troubleshoot how hardware and software behave together.

Takeaway: a working prototype and a better understanding of connected systems.

The student platform

A personal sandbox, not just a login.

Each student is intended to receive a managed server environment where they can deploy a site or service, configure it, monitor it and practise securing it.

That means learning the full lifecycle: build, release, operate, troubleshoot and defend.
